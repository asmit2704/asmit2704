## 01. About Me

I'm Asmit, a Computer Engineering student from India with a strong interest in cybersecurity, security operations, and digital investigations.

My primary focus is on understanding how security incidents happen, how suspicious activity can be detected, and how security teams investigate and respond to threats.

I enjoy turning concepts into working implementations through hands-on projects, security labs, Python automation, and technical research.

My current areas of interest include:

- Security Operations Center (SOC) and SIEM Engineering
- Threat Detection, Threat Hunting and Incident Response
- Digital Forensics and Incident Response (DFIR)
- Network Security and Traffic Analysis
- Cloud Security and Infrastructure Protection
- Security Automation and Applied Research

I'm currently strengthening my knowledge of cloud security while developing practical skills in security monitoring, threat investigation, and automation.

**Long-term direction:** Building expertise as a Cloud Security Engineer and eventually contributing to the design and leadership of security teams.
